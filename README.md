A silly mod that adds LazyMattMan, who reacts to things that Isaac does, to the game. This mod was made to showcase the capabilities of the FaceCam Mod!

Requires [FaceCam Mod](https://steamcommunity.com/sharedfiles/filedetails/?id=3828788794) and [ReactionAPI](https://steamcommunity.com/workshop/filedetails/?id=3096181411) to function correctly; regardless, your game should be able to run without issue if either mod is not enabled.

If you have any suggestions or bugs to report for the mod, please open a new issue, or contact me through Discord at **witherisafk**
